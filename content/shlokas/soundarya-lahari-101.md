## Shloka

**Devanagari:** ।। इति श्रीमत्परमहंसपरिव्राजकाचार्यस्य / श्रीगोविन्दभगवत्पूज्यपादशिष्यस्य / श्रीमच्छङ्करभगवतः कृतौ सौन्दर्यलहरी सम्पूर्णा ।। / (अनुबन्धः / समानीतः पद्भ्यां मणिमुकुरतामम्बरमणि / र्भयादास्यादन्तःस्तिमितकिरणश्रेणिमसृणः । / ( भयादास्य स्निग्धस्त्मित, भयादास्यस्यान्तःस्त्मित) / दधाति त्वद्वक्त्रंप्रतिफलनमश्रान्तविकचं / निरातङ्कं चन्द्रान्निजहृदयपङ्केरुहमिव ॥101॥
**IAST:** ।। iti śrīmatparamahaṃsaparivrājakācāryasya / śrīgovindabhagavatpūjyapādaśiṣyasya / śrīmacchaṅkarabhagavataḥ kṛtau saundaryalaharī sampūrṇā ।। / (anubandhaḥ / samānītaḥ padbhyāṃ maṇimukuratāmambaramaṇi / rbhayādāsyādantaḥstimitakiraṇaśreṇimasṛṇaḥ । / ( bhayādāsya snigdhastmita, bhayādāsyasyāntaḥstmita) / dadhāti tvadvaktraṃpratiphalanamaśrāntavikacaṃ / nirātaṅkaṃ candrānnijahṛdayapaṅkeruhamiva ॥101॥
**Say it:** iti śrīmatparamahaṃsaparivrājakācāryasya / śrīgovindabhagavatpūjyapādaśiṣyasya / śrīmacchaṅkarabhagavataḥ kṛtau saundaryalaharī sampūrṇā / (anubandhaḥ / samānītaḥ padbhyāṃ maṇimukuratāmambaramaṇi / rbhayādāsyādantaḥstimitakiraṇaśreṇimasṛṇaḥ / ( bhayādāsya snigdhastmita, bhayādāsyasyāntaḥstmita) / dadhāti tvadvaktraṃpratiphalanamaśrāntavikacaṃ / nirātaṅkaṃ candrānnijahṛdayapaṅkeruhamiva (draft — add stress CAPS in review)
