Placeholder workspace. The real Expo + React Native + TypeScript app is scaffolded in **Phase 6** of the developer plan (`dharma_daily_developer_plan.docx` §6).

- `@supabase/supabase-js` for auth + data

- Sentry + PostHog
- EAS Build / EAS Submit

Do not put Expo dependencies here until Phase 6 — keeping this empty avoids accidentally pinning Expo SDK versions before the rest of the backend is stable.
